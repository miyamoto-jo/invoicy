# invoicy
> 紙の請求書づくりを、スマホだけで。

インボイシーは請求書をサクッと作れる個人事業主向けアプリです。

---

## 1. なにができる？（一言で）

- **売上をスマホで記録**して、**期間指定で請求書を作成**できます。
- 作った請求書は **iPhone内部に保存**したり、**そのままメール送信**できます。
- 顧客や商品が増えても、**マスター管理**でかんたんに追加できます。

---

## 2. 請求書作成方法（ユーザーの具体的な行動）

### ① 売上登録（伝票を作成）

- お客さま（顧客）を選び、**注文があった商品と数量**を入力して登録します。
- 1回の登録が1枚の**伝票**として記録されます。

### ② 請求書を作成

- **締めたい期間**（例：当月）と、**対象の顧客**を選択します。
  - **複数の顧客**をまとめて請求書化することも可能です。
- 自動で集計され、**請求書のプレビュー**を表示します。

### ③ 保存・送信

- 作成した請求書を**iPhone内部に保存**できます。
- そのまま**相手先へメール送信**もできます（端末のメールアプリを利用）。

---

## 3. 機能一覧

### 3.1 請求書の保管と送信

- **保存**：作成した請求書を**端末内**に保存。
- **送信**：端末のメールアプリを使って、**メール送信**できます。
- **検索**：**期間指定**のほか、**顧客**で**フィルタリング**して探せます。

### 3.2 売上分析

- **期間を指定**し、売上を分析できます。
- 商品毎の売上を検索し、**注文の多い商品を確認**できます。

### 3.3 マスター管理

- 顧客、商品のデータを閲覧/登録/編集/削除 することができます。

---

## 4. マスター項目

> マスターの項目は暫定です。ご要望に沿って増減できます。

### 顧客マスター

- **顧客ID**
- **顧客名**
- **電話番号**
- **メールアドレス**

### 商品マスター

- **商品ID**
- **商品名**
- **税抜金額**
- **税率**

---

## 5. まとめ

- 第一要望の「**請求書を作成したい**」にフォーカスして、\
  **売上登録 → 請求書作成 → 保存/送信**までを**スマホ1台**で完結します。
- まずはこの範囲の最小構成でスタートし、実運用での気づきをもとに調整していきます。
