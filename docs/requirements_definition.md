# クリーニング店向け 請求書アプリ 要件定義（最新版 / for Cursor）

> 本書は**機能要件のみ**を記載します。詳細設計（画面遷移・データ構造・実装技術など）は**未記載**とします。

---

## 0. 前提・範囲
- 本アプリはオンライン接続を前提とし、オフライン時の動作は保証しない。
- データ保存は Google Drive を利用し、ユーザー操作時に即時アップロードする。
- バックエンド（自前サーバ）は構築せず、クライアント側の OAuth 認証と Drive API で完結する。
- 配布は個人利用を想定し、ブラウザ（または任意でPWA）で運用する。

> 以降は**ユーザーから提供された要件のみ**を反映しています。以前の資料にあった未合意の要件（印刷、バックアップZip、詳細アーキテクチャ等）は**削除**しました。

## 1. 機能要件

### 1.1 マスター管理機能

項目

### 1.2 売上管理機能
- **売上登録**
  - 顧客を選択し、注文のあった商品を登録して**伝票を作成**する。作成した伝票は**連携しているGoogleアカウントのDriveに保存**される。
- **売上閲覧**
  - **期間を指定**して売上を表示できる。
  - **顧客**や**商品**単位で**フィルタリング**できる。
- **請求書作成**
  - **月**を指定して、その月に発生した顧客の**伝票分**の請求書を作成する。
    - 締め日は顧客ごとに違うので、都度収集
  - 顧客を指定(複数)して、請求書を発行することも可能
  - 作成した請求書のjsonデータやpdfデータは**連携しているGoogleアカウントのDriveに保存**する。
- **月締めデータを出力する**
  - 請求書データを参照する。顧客と税込金額の情報を出す。
