# クリーニング店向け 請求書アプリ 要件定義（最新版 / for Cursor）

> 本書は**機能要件のみ**を記載します。詳細設計（画面遷移・データ構造・実装技術など）は**未記載**とします。

---

## 0. 前提・範囲
- 対象: 個人運用
- 想定端末: iPhone or Android。Googleアカウントと連携しGoogle Driveに保存する。
- 配布: 個人利用前提。バックエンド（サーバ）は構築しない。
- 目的: 紙で行っている請求書作成業務の効率化。

> 以降は**ユーザーから提供された要件のみ**を反映しています。以前の資料にあった未合意の要件（印刷、バックアップZip、詳細アーキテクチャ等）は**削除**しました。

## 1. 機能要件

### 1.1 マスター管理機能

#### 顧客マスター
機能: **閲覧 / 登録 / 更新 / 削除**

項目
| 項目 | 説明 |
|------|------|
| **顧客ID** | 顧客を一意に識別するID |
| **顧客名称** | 顧客の正式名称 |
| **顧客管理用名称** | 顧客管理用の略称・通称 |
| **顧客住所** | 顧客の住所情報 |
| **作成日時** | 作成日時 |
| **作成日時** | 更新日時 |

#### 商品マスター
機能: **閲覧 / 登録 / 更新 / 削除**

| 項目 | 説明 |
|------|------|
| **商品ID** | 商品を一意に識別するID |
| **商品名称** | 商品の正式名称 |
| **商品管理用名称** | 商品管理用の略称・通称 |
| **税抜金額** | 税抜きの商品価格 |
| **使用顧客** | その商品を使用する顧客 |
| **作成日時** | 作成日時 |
| **作成日時** | 更新日時 |


#### 消費税マスター
機能: **閲覧 / 登録 / 削除**

| 項目 | 説明 |
|------|------|
| **税率** | 税率の数値 |
| **作成日時** | 作成日時 |

### 1.2 売上管理機能
- **売上登録**
  - 顧客を選択し、注文のあった商品を登録して**伝票を作成**する。作成した伝票は**連携しているGoogleアカウントのDriveに保存**される。
- **売上閲覧**
  - **期間を指定**して売上を表示できる。
  - **顧客**や**商品**単位で**フィルタリング**できる。
- **請求書作成**
  - **期間**と**顧客**を指定して、その範囲にある**伝票分**の請求書を作成する。
  - **顧客は複数指定可能**。
  - 作成した請求書は**連携しているGoogleアカウントのDriveに保存**する。
