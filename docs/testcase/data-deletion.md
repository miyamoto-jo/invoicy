- [x] 請求書データ存在しない場合、ファイルが見つかりませんでしたと出る。
- [x] 空き容量が3GB以下の時、サイドバーのデータ削除の文字列が赤色になる。
- [x] 売上ファイルのファイル情報の表示に問題がない
- [x] 請求書ファイルのファイル情報の表示に問題がない
- [x] 売上ファイルを単体で削除することができる
- [x] 売上ファイルを複数で削除することができる
- [x] 請求書ファイルを単体で削除することができる
- [x] 請求書ファイルを複数で削除することができる
